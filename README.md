# הקורבה פוד · אתר דוגמה

אתר סטטי (HTML/CSS/JS ללא בנייה) לפודקאסט הקורבה פוד. אתר דוגמה בלתי רשמי.

- `index.html`, `episodes.html`, `blog.html`
- `assets/data.js`: רשימת הפרקים (נלקחה מערוץ היוטיוב) ופוסטים לדוגמה
- הסרטונים נטענים רק בלחיצה (youtube-nocookie)

להרצה מקומית: `python3 -m http.server`
